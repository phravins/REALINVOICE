# Installing RealInvoice

RealInvoice runs on your billing computer. Everything is stored on that computer, so
billing keeps working even when the internet is down.

You do not need any technical knowledge to install it. It takes about two minutes.

---

## Windows

### 1. Download the installer

Download **RealInvoice_0.2.0_x64-setup.exe**.

> Where from: your supplier will send you a download link, or give you the file on a
> pen drive.

### 2. Double-click the file you downloaded

Windows may show a blue box saying *"Windows protected your PC"*. This appears for any
new program. Click **More info**, then **Run anyway**.

### 3. Click through the installer

- A welcome screen appears — click **Next**.
- The licence screen appears — click **I Agree**.
- It shows where RealInvoice will be installed — **do not change this**, just click
  **Install**.
- Windows asks *"Do you want to allow this app to make changes to your device?"* —
  click **Yes**.
- A progress bar runs for a minute or so.

### 4. Finish

On the last screen, **leave both tick boxes ticked**:

- ☑ Create desktop shortcut
- ☑ Run RealInvoice

Click **Finish**. RealInvoice opens.

### 5. Opening it later

A **RealInvoice** icon is now on your Desktop. Double-click it any time. It is also in
the Start menu — press the Windows key and type `RealInvoice`.

---

## Signing in the first time

The very first time RealInvoice opens on a computer, it creates one account for you and
shows you the password **once**, on the sign-in screen, in a box headed *"First run on
this machine"*.

| | |
| --- | --- |
| **Username** | `admin` |
| **Password** | shown on screen — **write it down before signing in** |

The password is different on every computer, and it is **not shown again** after
somebody signs in. Keep it somewhere safe.

Type the username and password, click **Sign In**, and you are at the billing screen.

> **If you lose this password**, there is no way to reset it yet. Contact your supplier.

---

## Removing RealInvoice

1. Press the Windows key and type `Add or remove programs`.
2. Find **RealInvoice** in the list.
3. Click it, then click **Uninstall**.

---

## Linux

RealInvoice is also available as a single file that needs no installation.

1. Download **RealInvoice_0.2.0_amd64.AppImage**.
2. Right-click the file → **Properties** → **Permissions** →
   tick **Allow executing file as program**. Close the window.
3. Double-click the file. RealInvoice opens.

Then follow **Signing in the first time** above.

---

## Questions

**Does it need internet?**
No. RealInvoice bills, saves and prints entirely on your own computer.

**Where is my data kept?**
On this computer only. The exact location is shown under **Settings → About →
Database** inside the app.

**Can I install it on more than one computer?**
Yes. Each computer keeps its own invoices and its own sign-in password. Joining them
together is a later feature.
